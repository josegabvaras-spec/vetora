# Evidencia de los contratos de encargo de tratamiento

Coloca aquí los PDF de cada contrato, guardados desde el navegador (`Ctrl+P` → Guardar como PDF),
con este nombre de archivo:

```
AAAA-MM-DD_proveedor_dpa.pdf
```

Ejemplos: `2026-09-08_supabase_dpa.pdf`, `2026-09-08_vercel_dpa.pdf`, `2026-09-08_anthropic_dpa.pdf`.

El commit de Git que añade cada archivo sirve de sello de fecha — es la parte que hace que esto
sea evidencia y no solo un archivo guardado. No sobrescribas un PDF antiguo: añade uno nuevo con
la fecha de la nueva verificación, aunque el contenido no haya cambiado.

Ver [`CONTRATOS_ENCARGO_TRATAMIENTO.md`](../../CONTRATOS_ENCARGO_TRATAMIENTO.md) en la raíz del
proyecto — es el índice de qué debería haber aquí y el estado de cada proveedor.
